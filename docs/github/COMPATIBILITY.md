# 兼容性与已知限制

皮肤依赖 `xbmc.gui >= 5.17.0`、`xbmc.python >= 3.0.0`，Home 依赖 Python API 3.0.0。以实际 Kodi 的依赖判定安装支持，不强行忽略依赖。

主要验证环境为 CoreELEC。Windows 仅进行安装同步，没有启动 Kodi 做功能或界面测试；其他平台尚无完整接受证据。设计基准为 1920×1080、16:9，Default、Massive、Arial 有代表布局检查，不代表全部字体和分辨率都已覆盖。

## 媒体来源与 Emby

- 首页使用 Kodi 与 Emby 已有节点。评分已验证 Emby Next Gen `plugin.service.emby-next-gen` **11.1.27**；映射不唯一、身份不符、未验证版本、锁冲突或异常时保守回退。
- 播放前预选需要来源提供可靠资料，并能对应开播后的实际轨道；缺失或无法唯一确认时保留默认选择，可开播后手动切换。
- “记住本季”区分季偏好与本次选择，应用依赖准确的剧集/季身份和轨道对应。
- Emby 已看状态使用现有插件/服务端接口，保留真实观看和续播；无法查询、调用或核对的来源不能记作同步成功。
- 隐藏分库影响 YoPlayer 展示，不删除媒体或更改 Emby 访问权限。

不承诺任意插件版本、混合来源或缺少元数据的播放路径均有同样支持。
