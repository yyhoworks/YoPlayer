# 近期更新

2026 年 10 月 6 日：**Skin 2026.10.3.65 / Home 1.0.25**。以下汇总 56–65 版。

## 65：列表加载

评分在单次列表中批量只读核验，关库后构造条目，没有新增跨列表评分缓存。每日精选、最近添加、未观看、继续观看、历史和搜索完整构造后一次提交，保持顺序、URL、目录标识、评分、过滤和续播。

同一 CoreELEC 设备上 25 项列表的重复请求中位数：

| 场景 | 优化前 | 优化后 |
|---|---:|---:|
| 最近添加电影 | 2.68 秒 | 0.45 秒 |
| 最近添加剧集 | 1.10 秒 | 0.49 秒 |
| 继续观看 | 1.89 秒 | 0.50 秒 |
| 播放历史 | 1.51 秒 | 0.49 秒 |

数值为相邻两次重复请求的中点，未清系统缓存，不代表严格冷启动或电视滚动帧率。主要收益来自评分查询，批量提交本身约省 1 毫秒，搜索整体变化很小。

19 组成对实际请求中 18 组完整字段、顺序、URL 和评分相等。每日精选自然重选，仅实测数量和提交范围，固定输入的完整字段一致性由离线对照验证。
