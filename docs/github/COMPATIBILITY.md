# 兼容性与已知限制

皮肤依赖 `xbmc.gui >= 5.17.0`、`xbmc.python >= 3.0.0`，Home 依赖 Python API 3.0.0。以实际 Kodi 的依赖判定安装支持，不强行忽略依赖。

主要验证环境为 CoreELEC。Windows 为同一 CE 皮肤的辅助测试目标，历史安装和部分界面/原生操作证据不能代替 CE 验收；此次未连接或更新 Windows。其他平台尚无完整接受证据。设计基准为1920×1080、16:9，Default、Massive、Arial的历史代表布局检查不表示全部字体和分辨率均已覆盖。当前源码、CE安装和最新公开Release为Skin127 / Home1.0.38，最低Home依赖也是1.0.38。不存在由皮肤版本或xbmc.gui直接推断Kodi版本的依据。

## 媒体来源与 Emby

- 首页使用 Kodi 与 Emby 已有节点。评分已验证 Emby Next Gen `plugin.service.emby-next-gen` **11.1.27**；映射不唯一、身份不符、未验证版本、锁冲突或异常时保守回退。
- 播放前预选需要来源提供可靠资料，并能对应开播后的实际轨道；缺失或无法唯一确认时保留默认选择，可开播后手动切换。
- “记住本季”区分季偏好与本次选择，应用依赖准确的剧集/季身份和轨道对应。
- Emby 已看状态使用现有插件/服务端接口，保留真实观看和续播；无法查询、调用或核对的来源不能记作同步成功。
- 隐藏分库影响 YoPlayer 展示，不删除媒体或更改 Emby 访问权限。

不承诺任意插件版本、混合来源或缺少元数据的播放路径均有同样支持。

## 117的保守边界

- 兼容续播只对类型、DBID及完整文件路径都匹配的记录做一次绝对seekTime。无法确认ISO/多版本/插件解析后的身份时不猜测，保留原生播放选项；实际字幕/音轨行为需实机验证。
- 预告片只停止已确认归属的媒体。无法证明解析URL身份时不停止不明播放，可能需要用户用原生停止键关闭；离开详情后的底层插件延迟启动仍需验证。
- B站检索改为匿名公开接口，不读取或外发登录Cookie；认证播放/登录仍由B站插件负责。匿名接口可能限流或拒绝，当前无在线成功证据；不自动启用、安装或确认弹窗。
- 默认导演图片编辑保留既有显式操作与数据库写入路径，本轮仅将后台展示查询改为只读并隔离过期结果，未宣称消除该显式编辑风险。
