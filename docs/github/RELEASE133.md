# Skin 2026.10.3.133 / Home 1.0.41

合入 [PR #13](https://github.com/yyhoworks/YoPlayer/pull/13)，更新播放控制栏、暂停标记、字幕/音轨面板和只读播放详情。

- 点播播放中，短按上键进入控制按钮，下键进入进度区域，首次不跳时间；按钮与进度区域可上下往返或收起。遥控左右继续使用Kodi原生快退/快进步长，鼠标拖动保留原生滑块。
- 移动遥控器菜单短按继续开关详情，长按仍为playerdebug；详情方向键不影响播放位置。
- 轨道按钮先收起父控制栏再打开面板，避免父层计时影响操作；音轨页补齐静音导航，记忆按钮隐藏时也可到达；字幕列表有独立“关闭”行和延迟调节。
- 记忆操作携带媒体Token，在执行与持锁/原子写入前核对当前身份，重新读取偏好决定保存或取消；只改当前范围与轨道种类。
- 声道按数量显示，AAC profile归一，同名轨道可区分；保留CE直接返回的“评论”等原始轨道名称。

验证使用CoreELEC Kodi21.3的隔离非库样片，覆盖键位入口/焦点链、菜单详情、轨道选择与字幕关闭、静音状态往返、延迟调节、目录记忆保存/取消、普通/简洁模式、无字幕及记忆隐藏场景。15项离线回归和两门禁通过。详见[限定验证](VALIDATION133.md)。
