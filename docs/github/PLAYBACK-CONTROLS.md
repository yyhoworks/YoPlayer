# 播放方向键与菜单键

点播电影/剧集使用以下分工；左右步进沿用 Kodi 与用户的设置。

| 状态 | 左 / 右 | 上 | 下 |
|---|---|---|---|
| 播放画面、无操作面板 | 快退 / 快进 | 展开控制按钮 | 显示并聚焦进度条，首次不跳时间 |
| 控制按钮 | 在选集/章节、字幕、音轨、设置间移动 | 收起 | 到进度条 |
| 进度条 | 调整播放位置 | 到控制按钮 | 收起 |
| 轨道面板 | 标签处切页；字幕延迟行调值 | 上一项 | 下一项，跳过隐藏项 |

移动遥控器既有菜单键短按开关播放详情，长按保留 playerdebug。详情为只读，方向键不会穿透成快进/快退。返回先关闭最上层窗口，既有播放退出确认保持。没有菜单快捷键的设备可从更多播放设置中的播放信息入口打开详情。

独立模板位于 `source/skin.yoplayer.infuse/resources/keymaps/zzzz-yoplayer-playback-navigation.xml`。Kodi 安装插件包不会自动安装该文件；需要此入口时，先检查系统与活动 profile 的现有短按上下映射（含数字键别名），备份键位，再将这一个独立文件放入 `special://profile/keymaps/`，正常重启 Kodi 或执行 `Action(reloadkeymaps)`。存在冲突时应先选择保留哪项操作，不覆盖用户原 XML。

模板只接管全屏视频的短按上下键。其他皮肤及直播继续使用原生章节/大步进动作；没有可寻址进度时下键转入按钮组。首页与海报墙仍按原有焦点导航。已展开控制栏后由皮肤 XML 处理方向键。

“记住本季/本目录”是当前轨道的开关：当前选择已被记住时再次确认取消，否则保存当前选择。作用范围按实际媒体身份显示，影片变化后旧命令会被拒绝。关闭字幕可作为独立一行选择；不具备可靠季或目录身份时隐藏记忆开关。
