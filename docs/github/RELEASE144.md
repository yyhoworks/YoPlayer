# Skin 2026.10.3.144 / Home 1.0.43

144 修正五主题候选的首次提示和检查覆盖，包含143的XBT修复。Home保持1.0.43，主题PNG和XBT字节不变。

- **新安装不提示“改回经典”**：在首页派发启动脚本之前，为没有 `FirstTimeRun` 的用户记录本次提醒已处理。提示入口额外要求初始化标志存在，避免启动脚本稍后写入该标志导致误判。仅写提醒标志，不设置主题。
- **已处理用户不再启动额外提示脚本**：首页 `onload` 仅在旧用户、提醒未处理、主题为空时派发通知脚本；脚本内的播放、弹窗和页面保护仍保留。继续使用143的提醒标志，已看过提示者不会再次提示。
- **CI检查真正的生成素材**：CI新增执行已有的 `build_theme_assets.py --check`，补齐主题定义→PNG→XBT的检查链。新增真实调色板故障注入测试，避免“PNG与XBT彼此一致、但都不符合themes.json”漏过。
- **拒绝孤儿主题条目**：主题目录的散图与XBT条目要求双向集合一致；即使删除了最后一张散图，残留的包内条目也会使检查失败。原有非主题包独有资源继续保留。此项仅更新开发检查与回归，不改变144运行文件或交付包。

143 XBT从53,841,818字节降为51,598,898字节主要来自重复帧共用偏移：2600帧使用2099个唯一偏移，即501帧复用。相同新帧数据不去重需53,877,584字节，去重节约2,278,686字节；主题增删及重编码另有净增。Kodi自己的TexturePacker也支持此类去重。144保留同一XBT，不再次重打包。

## 升级与验证

使用新的144归档，不覆盖已保存的142或143包。相对143，运行文件仅改Home.xml、addon.xml与changelog.txt，无新增/退役运行文件；仓库提交还包括CI、检查工具和文档。相对141的暖沙98个散图退役清单仍适用。

文档或PR中的ZIP SHA256用于核对那一次构建的制品，不保证全新检出重建相同归档字节。当前打包器写入构建当时的时间；存在已交付同版本同内容包时则复用其原ZIP。独立重建应比较成员路径与解压后的文件内容。
