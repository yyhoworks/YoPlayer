# Skin 2026.10.3.142 / Home 1.0.43

## 变化

- 五套主题：墨黑（新默认）、石墨暖金、雾白、深海、经典（原样）。暖沙并入雾白。详见[主题说明](THEMES.md)。
- 焦点统一为白色（雾白为近黑），暖金和雾蓝只作状态色。首页卡片进度条随主题着色。
- 深色主题下，首页、媒体库和搜索上的弹窗改用深色样式。设置、详情和播放保持原样。
- 主题配色页改为列表加实时预览，整页随焦点变色。
- 首页焦点卡片加描边；分库标题只在焦点或无封面时显示；选择框显示“当前/已选”，单页不显示页码，取消按钮可见。
- 播放OSD提示移到左上并在4秒后淡出；弹窗和快进条出现时隐藏格式角标。

Home 无变化。没有改动播放器、解码或系统组件。

## 升级

安装 Skin 142 覆盖 141。相对 141 退役 98 个文件：`media/infuse/themes/sand/` 整个目录。新增 `media/infuse/themes/ink/`、`media/infuse/progress_fill_white.png` 和 `media/infuse/home/focus-ring.png`。

未选过主题的用户升级后看到墨黑；原经典用户需要在主题配色中重新选“经典”。

## 限制

- 继续观看卡片不显示“剩余时间”：Kodi 列表项没有剩余时长标签，Home 也未提供，需要另行改动 Home。
- 播放中弹窗的偏青底色（与 OSD 中性灰不一致）属于播放画面，本版未改。

验证范围见[限定验证](VALIDATION142.md)。
