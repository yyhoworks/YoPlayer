# 133 限定验证

运行环境为CoreELEC Kodi21.3-Omega-f10。使用任务自有的5音轨/5字幕/4章节样片与2音轨/无字幕样片，不播放真实库、不扫描媒体。

- 15项离线回归覆盖媒体切换拒绝、锁内与提交前切换拒绝、记忆保存/取消、其他范围与种类保持、声道数量/AAC/重复标题、关闭字幕的媒体key、静音导航、按键入口与其他皮肤/直播回落。
- 原始键位软件事件确认短按上下进入正确区域，首次不seek；菜单开关详情且详情方向键不影响播放。
- 两窗口验证音轨与字幕列表、字幕开关/延迟、静音状态往返；有/无记忆按钮时静音及更多设置均可上下到达，无字幕列表及空提示正常。
- 目录记忆实际保存音轨与关闭字幕状态，再次点击取消；其他偏好保持。简洁模式标题仍可区分，CE的“评论”名称保留。
- 133将遥控进度焦点从百分比滑块分离到原生StepBack/StepForward，鼠标滑块保持；确认轮单独验证左右步进及音轨原生index选择。
- 安装树逐成员匹配包；用户历史、观看/续播字段、偏好、队列和退出策略按本轮新鲜快照核对，样片状态独立清理。

早期脚本的等待条件/异步输入时序失败保留，未计入通过；黑帧截图不作视觉证据。129/130原包和问题记录保留，未覆盖同版本归档。

这些结果只覆盖本轮皮肤/native绑定。真实Emby/本季分支、实体电视/遥控/CEC、可听静音输出、HDR/DoVi硬件表现与性能仍待相应验证；不声明完整播放器验收。
