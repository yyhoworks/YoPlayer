### 详情、季集与现有 Kodi / Emby 绑定

- 遮住版本/附加内容选择器和管理弹窗背后的详情前景，关闭后恢复详情。
- 从详情发起的电影与剧集播放停止后返回对应详情，保留剧集、季和集上下文；处理原生播放器 schema 与停止过渡，界面或播放上下文被替换时取消返回。
- 修复多版本媒体的已看操作身份匹配及更新后的单集卡片即时刷新；保留播放次数、历史、续播和并发观看保护。
- 分库剧集卡片显示未看集数，电影卡片显示原生续播进度。
- 搜索按实际可见条目补齐分页，先核对媒体身份再过滤旧历史，避免隐藏分库挤占可见搜索结果。
- 延续可靠来源的播放前音轨/字幕预选、本季记忆、隐藏分库与真实观看记录；不扫描、清库或新增播放器服务。
