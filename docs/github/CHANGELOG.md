# YoPlayer 2026.10.3.63 更新说明

发布日期：2026年10月6日  
皮肤版本：2026.10.3.63 · 首页组件：1.0.24

本版重点修复播放前选择简体、繁体字幕时的识别问题，并延续首页和片库按钮的简洁显示。以下同时汇总 2026.10.3.56–63 的近期改进。

## 本版修复

- **简繁字幕选择更准确**：修复 Emby 与 Kodi 对同一字幕使用不同名称时，播放前选择繁体字幕、实际播放仍使用简体的问题。遇到无法唯一确认的轨道时，保留原有选择，避免误切换。

## 近期体验改进

- **首页和片库按钮更简洁**：圆按钮平时只显示图标，选中时在下方显示名称；移开焦点或打开菜单后隐藏名称。首页搜索文字保留。
- **音轨、字幕面板更易读**：当前语言、格式和状态分层显示，开关、已选轨道、更多设置与返回提示更清楚；没有提供轨道资料时显示明确说明。
- **“记住本季”操作更稳定**：明确偏好作用于本季还是当前播放，修复资料刷新时已选中的记忆操作短暂消失的问题。
- **选集信息更清晰**：当前播放季集与可选集数分两行显示，当前播放行采用“第N集＋集名”的中文表达。
- **详情评分减少重复**：显示有效 Emby 评分时收拢重复评分；评分胶囊缺值时，资料行保留可用评分。
- **设置与系统信息更清楚**：改善入口说明、页脚和长文本显示，系统 CPU、内存进度使用真实数据，明确网络就绪等待的用途。
