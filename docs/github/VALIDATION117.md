## 已知未通过项

### P2：1143确认框初始焦点未落到取消

- 位置：[custom_1143_Confirm.xml:3](../../source/skin.yoplayer.infuse/1080p/custom_1143_Confirm.xml#L3)，用途初始化第5–6行，取消按钮可见条件第116/153行。
- 触发与影响：停止/复位两种用途、暂停播放场景下初次打开运行时窗口11143，用途冻结正确，但无按钮焦点；按左键后才进入“否”，Back可返回。日志明确提示“Control 10 in window 11143 has been asked to focus, but it can't”。默认取消体验未实现，测试没有执行皮肤复位。
- 原因边界：按钮可见性依赖onload属性已确认，但可见性初始化时序或重复ID解析是否参与仍待定位；不能将所有重复ID一概判错。
- 最小后续建议：保持布局与用途冻结，确保默认聚焦时有稳定可见的取消控件；评估共享按钮/条件动作或经验证的初始化顺序，不以无依据延时抢焦点掩盖问题。
- 验证/回归：冷打开、再次打开、暂停、停止后分别验证焦点10与Back恢复；停止用途不能切换为复位。不要为测试确认执行真实复位，避免焦点修复改变危险动作绑定。
- 依据：[Kodi Window Structure](https://kodi.wiki/view/Window_Structure)、[布尔条件](https://kodi.wiki/view/List_of_boolean_conditions)。Wiki为滚动文档，实际测试目标为Kodi21.3-Omega-f10；“默认取消”是工程安全判断，不是Kodi强制规范。

### P2：无播放时预告片误提示先停止播放

- 位置：[infuse_trailer_session.py:29](../../source/skin.yoplayer.infuse/scripts/infuse_trailer_session.py#L29)、[trailerurl.py:11](../../source/skin.yoplayer.infuse/scripts/trailerurl.py#L11)及第17行文案。
- 触发与影响：无活动播放器时，从剧集详情进入现有预告片绑定；预告片窗口已可见/Active、详情身份正确，却未取得请求Token并提示“请先停止当前播放”。没有继续加载，提示与实际播放状态不符；Back恢复详情焦点，观察期无迟到播放。
- 原因边界：begin有多种失败原因，调用端却统一使用播放中提示，反馈分类缺陷已确认；首次失败的瞬时分支仍待定位。设备未安装Bili插件，但没有到达正确的缺依赖提示，不能据此判为正常。
- 最小后续建议：区分已有播放、窗口未就绪、身份/路径缺失、已有请求，保留归属与取消保护，仅在证实竞态后做有界处理。
- 验证/回归：无播放/背景播放、本地/SMB/URL/Bili缺失与失败、慢加载Back、换详情和重复进入；不得迟到启动或误停其他媒体。回归风险包括过度放宽身份检查、重复请求、取消后播放。
- 依据：错误分类为工程判断；[Kodi 21.3 Python Player契约](https://github.com/xbmc/xbmc/blob/21.3-Omega/xbmc/interfaces/legacy/Player.h)用于核对播放状态接口，不代表定制f10与上游完全等价。

以上问题尚未修复；不覆盖已交付117运行文件。后续修复须另行升版。
