# 主题配色与单一 VI

Skin 2026.10.3.109 提供五种主题。进入“皮肤设置 → 界面显示 → 主题配色”，用方向键查看五套配色样本，按确定保存。返回或取消撤销预览；“恢复经典”只复位配色。选用标记与遥控焦点分开，方便遥控操作。

经典继续使用原浅蓝灰和已有偏好。雾白适合明亮客厅，暖沙适合暖光环境，石墨适合中性夜间观影，深海适合低饱和冷色偏好。

| 主题 | 背景 | 表面 | 浮起层 | 主文字 | 次文字 | 焦点 |
|---|---|---|---|---|---|---|
| 雾白 | #ECEDF1 | #F5F5F7 | #FFFFFF | #1D1D1F | #56565C | #0A6B54 |
| 暖沙 | #E8E2D8 | #F4F0E8 | #FFFBF5 | #292419 | #6B6252 | #8C5E2A |
| 石墨 | #141416 | #1D1D1F | #2C2C2E | #F5F5F7 | #B5B5BB | #8FD4C2 |
| 深海 | #10161D | #1A2530 | #243442 | #E8EDF2 | #9AA8B4 | #9CC4E4 |

雾白填充图形用 #0E9F7E，小字和细线用 #0A6B54；暖沙强调文字用 #7F5626。两套深色主题的分隔色均为 #56565C。

主题仅改变首页、资料库、搜索浏览中的页面底色、普通实底面板、其上的标题/正文/辅助文字和既有普通列表选中填充。首页卡片标题、中文季集和分库名继续居中。工具名称在获得焦点时显示，移开隐藏。海报、剧照、影片标志和播放画面保留原色。

全部设置（含皮肤设置和主题选择外框）、系统/信息工具、插件管理、配置/媒体库管理/快捷/排序菜单、确认框、键盘与其他输入弹窗使用固定功能样式，保留后续文字、焦点与玻璃层次修复。五个主题预览色块继续展示各配色。最新 VI、主题功能、完整状态文字与导航修复保留。

GlobalSearch 的专用背景、普通面板、标题及默认50列表文字适配主题；51与其他旧视图保留65材质。YoPlayer自有搜索目录沿用媒体库浏览样式。已有自定义背景、媒体图和播放背景不被主题图片替换。

正式 VI 以最新 PPTX 为权威，采用单一 Y 形负空间标志。浅底使用冷墨蓝 #1F2933，深底使用近白 #F5F5F7，不使用主题强调色。运行与预览使用 PPTX 原 PNG；见 [VI 规范及来源边界](../vi/README.md)。

五种主题保留已确认色值。表中强调色用于获准的普通浏览面板，不作为全局控件染色。评分、错误等功能色按已有语义保留。

叠在媒体上的玻璃框、详情主副按钮、播放 OSD、四圆按钮、播放条与原生播放设置，以及首页搜索/工具、片库圆按钮、开关/滑条、未看标记和卡片小进度，使用固定功能材质，不随五套浏览主题染色。75–89 版继续调整了玻璃层次、详情按钮、弹窗和播放进度：详情音轨/字幕预选底板约 75% 不透明，其他面板保持各自材质。复合上下箭头保留原底与图形，状态文字和开关留出间隔；保留已确认原生圆角修复。

焦点预览使用 Kodi 原生变量和静态图片；按确定保存后界面短暂重载一次，浏览页面应用配色。方向预览不会写入选用值，保存后的 `YoPlayerTheme` 纳入外观偏好备份与恢复。没有自由 HEX 输入、额外轮询、实时模糊或背景取色。设置、片库和播放面板的已有功能保持。

色值检查只读运行源码；`python tools/check_themes.py` 可独立运行，也由仓库检查调用。静态素材生成需要 Pillow，使用 `python tools/build_theme_assets.py` 显式执行，普通检查和打包只依赖 Python 标准库。实体电视、遥控和 CEC 验收另行确认。
