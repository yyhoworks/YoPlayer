# Skin 2026.10.3.143 / Home 1.0.43

143 修复五主题候选 142 的打包与升级提示问题，包含 142 的五主题和 UI 调整。Home 保持 1.0.43。

- **主题贴图实际生效**：更新 `Textures.xbt` 中 58 个旧主题图条目，加入墨黑的 98 张图和 2 张共享素材，删除暖沙的 98 个旧条目。所有 393 张主题图与包内像素一致。保留其余 2442 个原有条目，包括 1589 个没有散图副本的有效旧资源。
- **默认主题提醒**：主题保存值为空且尚未收到本次提醒的用户，进入首页时收到一次静音通知，说明默认已改为墨黑，并告知可在“主题配色”中选回“经典”。播放、模态窗口或离开首页时不提醒，待下次进入首页再判断。不会代替用户写入主题选择。旧版经典与未选主题都存为空值，因此无法只识别旧经典用户。
- **主题条件一致**：深海选择框颜色复用支持预览和别名的主题表达式；偏好 choices 恢复逐行排版。
- **生成工具安全**：PNG 与 XML 生成器都支持只读 `--check`，未知参数在生成前报错；PNG 比较解码像素，跳过像素相同的输出，避免仅因编码器不同而重写文件。
- **CI 覆盖**：仓库检查增加 XBT/散图像素比较、退役条目及主题覆盖检查；新增 12 项针对打包、只读生成和通知保护的回归。历史 3 处非主题差异以双方固定哈希记录，任一侧变化会重新失败。

## 升级与退役

安装 143 使用新版本归档，已交付的 142 包保持原字节。相对 141，仍需退役散图目录 `media/infuse/themes/sand/` 的 98 个文件；相对 142，没有新增的散文件退役，替换 XBT 会移除其中的暖沙条目。不会删除其他主题、字体或许可证，不改 Home、播放器、系统和内核。

本版尚未部署，验证范围与保留问题见 [143 限定验证](VALIDATION143.md)。142 的设备截图不能作为本版 XBT 或通知的实机验收。
