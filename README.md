# YoPlayer

历史源码快照：**Skin 2026.10.3.64 / Home 1.0.24**。

本标签由核验过的已交付插件 ZIP 导入，运行成员保持原字节。主分支保存最新源码；下载区只保留最近三版 63、64、65。

[安装说明](INSTALL.md) · [本版更新](docs/github/CHANGELOG.md) · [独立构建](docs/github/DEVELOPMENT.md) · [Releases](https://github.com/luyang1104/YoPlayer/releases)

电视媒体界面基于 Minsk Infuse / Kodi Confluence，包含首页、分库、续播、详情、音轨和字幕操作。已完成对应范围的离线、Windows 同步和 CoreELEC 验证；实体电视、硬解/HDR、遥控和 CEC 仍需人工确认。
