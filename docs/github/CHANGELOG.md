# YoPlayer 2026.10.3.64 更新说明

发布日期：2026年10月6日  
皮肤版本：2026.10.3.64 · 首页组件：1.0.24

本版集中补齐静音开关与播放信息的显示细节。

- **静音开关更直观**：普通、简洁音轨面板，以及从字幕入口切到音轨的面板，统一使用灰蓝胶囊和白色圆点。未静音圆点在左，静音时在右；原遥控操作与选轨标记保持。
- **无字幕状态更准确**：播放信息优先判断是否有可用字幕，避免将“没有字幕轨”显示为“语言未提供”；有字幕但关闭时显示“已关闭”。
- **静音时保留完整音轨信息**：语言、编码格式、声道与真实音量继续显示，另外标明“已静音”。
- **字号适配已复核**：完成Default、Massive和Arial代表布局检查。

已完成离线验证、Windows安装同步及CoreELEC受影响范围自动验收，本轮测试产生的观看、续播、轨道与偏好变化已恢复。实体电视、硬解/HDR及遥控器/CEC仍待人工确认；自然缺语言字幕样本尚未取得。
