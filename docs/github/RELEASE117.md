# YoPlayer 2026.10.3.117 / Home 1.0.37

基于115的皮肤修复版，保留首页分区、设置5+5和OSD布局。附件为已核验并安装到CoreELEC的原包。

**限定测试部分通过，仍有两项P2未通过；本次发布不表示完整CoreELEC验收。**

## 更新

- 固定确认框用途，防止播放停止后切换为设置复位；初始取消焦点仍有已知问题。
- 详情关闭取消无条件Stop；预告片增加请求归属、身份核对和取消保护。
- 兼容续播按媒体类型、DBID和完整路径核对身份，使用一次绝对seekTime，保留Kodi原生选项。
- 隔离导演/评分后台过期结果，补齐字体角色，区分首页加载、空态和错误。
- 保持115布局；Home1.0.37运行源码不变。相对115为20修改、1新增、0退役。

## 已知问题

1. **确认框1143初次打开无按钮焦点**：stop/reset及暂停场景复现，按左键才进入“否”；Back可以取消。默认取消体验未实现，测试未执行真实设置复位。
2. **无播放时预告片错误提示“请先停止当前播放”**：反馈分类缺陷已确认，首次请求失败的具体时序仍待定位；Bili缺失不能解释该错误提示。

两项均尚未修复，后续运行修复将使用新版本。完整因果、源码位置和复测建议见[117限定测试报告](https://github.com/yyhoworks/YoPlayer/blob/v2026.10.3.117/docs/github/VALIDATION117.md)。
