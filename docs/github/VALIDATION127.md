# 127 轨道面板的限定验证

2026-10-31 在 CoreELEC、Kodi `21.3-Omega-f10` 上，对 PR #10 的 `762d75b` 做了定向验证。正式127的 `Custom_1145_OSD_audio.xml` 与受测候选逐字节相同，其他运行差量只有版本说明。

## 通过的场景

- 普通/简洁模式下，音轨与字幕 tab、列表及上下导航符合预期；实际播放器音轨 index、字幕 index 与字幕开关对应所选项目。
- 两种模式都实际点击记忆按钮，确认隔离样片目录的音轨/字幕偏好写入；保留原有偏好。
- 面板打开时双向切换 simpleaudio，列表和焦点保持。
- 两种模式各三次重新打开并选择音轨，初始首项有检查；实际选轨均正确。正式125也完成两种模式各三次对照。
- 无字幕样片的两种模式下，空字幕提示及按钮导航正常，音轨仍可切换；正常停止播放关闭面板。
- 本轮未出现 Kodi 段错误或服务自动重启。

使用两个隔离静音样片，各有英语/日语两条音轨，分别带一条 SRT 和无字幕。主要 UI 检查在暂停状态完成，选轨后确认 speed 仍为0。由外部 JSON-RPC/原生按键驱动，不访问 Python 原生 Control 对象；使用显式检查，不使用会被 Kodi 优化模式移除的 assert。

## 限制与保留问题

- 记忆测试覆盖现有“同一剧集目录”分支，真实 Emby 来源与原生库“本季”身份分支未覆盖；实体电视、实体遥控及 CEC 留待人工。
- 初次/静置面板自动收起，以及无播放时强制设焦能指向隐藏记忆按钮，在125也复现；不归为本PR新增回归。普通上下键会跳过该隐藏按钮。未查定自动收起的具体触发方。
- 早期脚本的就绪门槛、光标复位和不同事件队列时序失败已保留，不计通过。最终对照在明确首项与事件等待后通过。
- 此前候选测试期间发生过 exit139，本轮未复现，不等于已查明或修复其原因。
- 未证明性能提升，也未完成完整播放、音视频输出或全来源验收。

实际媒体库未用于播放测试，没有扫描媒体；样片记录和独立记忆项已条件清理，真实观看、断点、偏好和队列核对保持。源码只改皮肤XML与版本说明，播放器、解码器、系统和内核保持既有实现。
